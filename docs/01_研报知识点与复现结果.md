## 0. 60 秒电梯陈述（面试开场用）

> 我复现了开源证券一篇把「因子切割论」和 GRU 结合的研报。核心思想是：
> 一段 20 日的涨跌幅里，信息在时间轴上分布不均匀——大单成交的日子和散户主导的日子
> 含的信息不一样，所以要先用「切割指标」把这 20 天切成两半，再加工。
> 研报把这个切割动作写进了网络结构：两个 GRU 分支分别吃掩码后的序列，取最后时刻隐藏状态之差，
> 就是 DBD-GRU。
> 我在沪深300 上用 5 年训练 + 1 年验证 + 1 年测试的年度滚动，跑了 2015–2025 共 11 折。
> 结果是：合成后的 DBD 两因子 RankIC −5.54%，研报在沪深300 上报告的是 −5.76%，差 0.22 个百分点；
> 但我也发现两件事——DBD 的增量主要来自早四年，2022 年后它已经跑不赢原始切割因子；
> 而且第三分支因为缺小单主动买卖数据做不了，我只做了两因子，没有拿替代品凑数。

## 1. 研报的知识脉络

### 1.1 起点：反转因子「用之不安、弃之可惜」

A 股反转效应显著，最朴素的代理变量是 `Ret20`（近 20 日涨跌幅）。问题是：

- 收益很强，但**稳定性很差**、回撤大；
- 直接丢掉可惜，直接用又拿不住。

研报没有去调参，而是换了个问法：**Ret20 是一段区间的加总，那组成它的每一天，贡献是一样的吗？**

答案显然不是。信息在时间轴上分布不均匀。于是有了**切割**。

### 1.2 因子切割论三要素

| 要素 | 定义 | 理想反转因子 |
| --- | --- | --- |
| **对象** | 具有**可加性**的目标变量 | 日涨跌幅 |
| **刀法** | 有区分能力的**切割指标** | 日均单笔成交金额 = 成交金额 / 成交笔数 |
| **产出** | 对切割后变量的再加工 | `M = M_high − M_low` |

**「可加性」是硬约束**，这是面试最爱问的边界。判断标准：
把整体的量在时间轴上切开后，每一部分的**变量含义是否保持不变**、能不能重新加总。

- ✅ 可加：涨跌幅、换手率、成交量、振幅
- ❌ 不可加：流通市值、市盈率、PB

（市值切成两半以后，每一半不再是"市值"，而是别的含义，不能加总回原变量。）

**「刀法」是核心**。切割指标必须能区分投资者的行为状态。研报其他因子里的刀法：
聪明钱因子用「机构参与痕迹」在分钟数据上切；APM 因子直接按「日内交易时段」切；
理想振幅因子按「股票高低价态」切。

**「产出」里藏着一个反直觉的点**：研报明确推荐「相减或相除」，而不是只取信息含量高的那一半。
理由是——**相减在隐蔽处起到了标准化的作用**。被减去的那一半通常**不贡献收益增量**，
却提供了一个公允的水准线，从而提升因子稳定性。

> 这是一道高频面试题：**"为什么不直接用 M_high，而要 M_high − M_low？"**
> 标准答：M_low 提供标准化基准，扣除后消除掉全市场共同的水平漂移，因子更稳；
> 研报也指出可以只用一半（主动买卖因子就是只取一半），但那是有意为之，不是默认做法。

### 1.3 三个切割论因子

| 因子 | 切割指标 A（刀） | 切割对象 B（对象） | 切割比例 | 聚合 | 产出 |
| --- | --- | --- | --- | --- | --- |
| **理想反转** | 日均单笔成交金额 | 日涨跌幅 | 50% / 50%（10 日 / 10 日） | `sum` | 高 − 低 |
| **理想振幅** | 收盘价高低状态 | 日振幅 `high/low − 1` | 25% / 25% | `mean` | 高价态 − 低价态 |
| **主动买卖（小单）** | 收盘价高低状态 | 小单流入强度 | 25% | `mean` | **只取低价态**（不相减） |

主动买卖因子只取一半，研报自己解释了后果：**因为原因子里没有"相减"的结构，
所以它与对应的 DBD 因子相关性较低**（研报 P14）。

### 1.4 微观逻辑：为什么这么切能切出东西

研报在《A 股反转之力的微观来源》里给出的解释链条：

```
反转效应 ← 投资者跟风 + 过度反应
跟风/过度反应 ← 在大单交易更多的时候更强烈
大单成交多 → 当天的平均单笔成交金额更大
∴ 用「平均单笔成交金额」切涨跌幅，能把"含反转信息的日子"分离出来
```

一句话：**反转之力的微观来源是大单成交。**

这也是判断一个"刀法"好不好的标准：**你对切割对象所表征的交易行为，理解得够不够深。**

### 1.5 代码实现（`research/features.py`）

```python
def cut(a, b, fraction=.5, aggregation='sum'):
    # a = 切割指标, b = 切割对象, 窗口固定 20 日
    order = np.argsort(a, kind='stable')      # 稳定排序：并列时旧的在前
    k = int(len(a) * fraction)
    fn = np.sum if aggregation == 'sum' else np.mean
    return float(fn(b[order[-k:]]) - fn(b[order[:k]]))   # 高组 − 低组
```

调用：

```python
sources['cut_amplitude'] = (close, amplitude, .25, 'mean')     # 按收盘价切振幅
sources['cut_reversal']  = (avg_trade_amount, return, .5, 'sum')  # 按单笔金额切涨跌幅
```

三个实现细节值得单独说（都是面试加分项）：

1. **用 `argsort(kind='stable')` 而不是普通排序**——并列值必须有确定规则，否则因子不可复现；
2. **窗口必须是 20 个连续交易日且全部有限**——`valid = isfinite(A) & isfinite(B) & (volume>0)`，
   缺失**不填零**；
3. **不要用成交量当成交笔数**——理想反转要的是"平均单笔成交金额"，
   分子是成交金额（跨供应商拼接，已做单位审计），分母是真实成交笔数（Wind 导出）。

## 2. DBD-GRU：把切割写进架构

### 2.1 结构

输入 `x ∈ R^{20×2}`：通道 0 = 切割指标 A，通道 1 = 切割对象 B。

```
A 序列 ── 取时序中位数 ──→ mask_high (A >= 中位数) / mask_low (A < 中位数)
                              │                        │
        x ⊙ mask_high ──→ GRU_high ──┐
                                      ├─→ h_high − h_low ─→ Linear(64,1) ─→ score
        x ⊙ mask_low  ──→ GRU_low  ──┘
```

普通 GRU 基线：**同样 20×2 输入，不做掩码**，直接 `GRU(x)[-1] → Linear`。

### 2.2 它与"两个 GRU"的本质区别

不是把网络加宽，而是**把先验编码进结构**。三点：

1. 差分是**硬约束**：输出只能表达"高组与低组的差异"，模型没法偷懒去学一个整体的时序动量；
2. 两个分支**共享输入分布、只差掩码**，因此差异部分天然对应"切割出来的信息"；
3. 参数量 GRU 38,081 vs DBD-GRU 76,097（约 2 倍）——
   **这一点必须主动披露**，因为增益有可能部分来自参数量。本项目未做参数量对齐对照，
   已列在 `model_parameters.json` 的 `not_done` 里。

### 2.3 掩码的四个实现决策（`research/neural.py`）

```python
def masks(x):
    high = x[:,:,0] >= torch.quantile(x[:,:,0], .5, dim=1, keepdim=True)
    return high.unsqueeze(-1), (~high).unsqueeze(-1)
```

| 决策 | 实现 | 为什么 |
| --- | --- | --- |
| 阈值 | 用 `quantile(.5)` 即**算术中位数**（偶数长度的均值） | 20 是偶数，中位数有两种定义，必须固定一种 |
| 并列 | `>=` 归入 high，`<` 归入 low | 明确规则，不留歧义 |
| 遮零粒度 | **整行置零**（两个通道一起） | 时间步保留，信息位置不丢；不是删除时间步 |
| 序列长度 | **保持 20 步不变** | 删步会破坏时序对齐 |

### 2.4 训练目标：ICLoss

```python
def ic_loss(score, y):
    score = score - score.mean(); y = y - y.mean()
    return -(score * y).sum() / (score.square().sum() * y.square().sum()).sqrt().clamp_min(1e-8)
```

直接对**单日截面的 Pearson IC** 取负做损失，而不是 MSE。
这很关键：因子任务的评价口径就是 IC，用 IC 做损失**目标与评价一致**。
batch = **一个完整交易日截面**（股票数动态），不是固定 batch size。

## 4. 结果解读

### 4.1 【最强证据】与研报沪深300 口径的直接对比

研报摘要给出的 DBD-Combine 在各宽基的 RankIC：

| 股票池 | 研报 DBD-Combine RankIC | 本项目 | 差值 |
| --- | ---: | ---: | --- |
| **沪深300** | **−5.76%** | **−5.54%**（dbd_two_factor） | **0.22 pp** |
| 中证500 | −7.40% | 未测 | — |
| 中证1000 | −9.84% | 未测 | — |

说明：

- 研报是**三因子**对称正交合成，本项目只有**两因子**（缺主动买卖分支）；
- 区间不同（研报 2014-12~2025-05，本项目 2015-01~2025-12）；
- 本项目未做中性化，研报做了市值行业中性化。

在这样的差异下仍落在 0.22 个百分点内，**说明因子构造与 DBD 结构的复现是站得住的**。

同时，**符号方向也完全对上了**：研报三个 DBD 因子 RankIC 均为负（−10.3% / −10.3% / −9.8%），
本项目 `dbd_amplitude` −5.79%、`dbd_reversal` −3.04%、`dbd_two_factor` −5.54%，**同为负**。

> 注意：本项目在 `summary.csv` 中报告的是**符号对齐后的正值**（正值代表有效），
> `results_raw_factors/summary.csv` 里同时保留了 `original_raw_RankIC`（负值）以便核对。
> **面试时一定要先说清符号口径**，否则会被认为数字对不上研报。

### 4.2 单因子量级为什么比研报弱？研报自己的数据给出了答案

研报单因子（全 A）：理想振幅-DBD −10.33%、理想反转-DBD −10.3%。
本项目（沪深300）：−5.79%、−3.04%。差了近一半。

**恰恰是研报自己的表格解释了这个差距**：DBD-Combine 在
沪深300(−5.76%) → 中证500(−7.40%) → 中证1000(−9.84%) 上**单调变强**。

即：**微观结构类因子在大票上天然更弱**。本项目的股票池是沪深300，
量级只有全 A 的一半，完全符合这一规律，而不是复现错误。

### 4.3 显著性：哪些结论站得住，哪些站不住

配对移动块 bootstrap（块长 21 日、2,000 次，日频 RankIC 差值）：

| 对比 | Δ mean | 95% CI | 结论 |
| --- | ---: | --- | --- |
| dbd_amplitude − gru_amplitude | **+0.0589** | [+0.0420, +0.0761] | **显著** ✅ |
| dbd_reversal − raw_reversal | −0.0213 | [−0.0424, −0.0017] | **显著为负** ⚠️ |
| dbd_amplitude − raw_amplitude | +0.0006 | [−0.0178, +0.0184] | 不显著 |
| dbd_reversal − gru_reversal | +0.0054 | [−0.0089, +0.0204] | 不显著 |
| dbd_two_factor − alpha158 | −0.0053 | [−0.0228, +0.0129] | 不显著 |

**我的诚实结论**（这三句是整个项目的核心判断）：

1. **DBD 相对普通 GRU 的架构增益是稳健的**——振幅分支 Δ=+0.059，置信区间远离 0。
   这与研报"DBD 不是 GRU 与切割因子的简单叠加"的定性主张方向一致。
2. **但 DBD 相对原始切割因子、相对 Alpha158 基线，增量都不显著。**
   反转分支甚至**显著弱于**原始切割因子。
3. 所以我不会说"我复现出了研报的优异表现"，而是说
   **"我复现出了因子与结构，验证了一部分主张，也定位了哪些主张在我的数据条件下不成立"。**

### 4.4 增量消融

| 实验 | RankIC | CAGR | IR |
| --- | ---: | ---: | ---: |
| E0 Alpha158 基线 | 0.0585 | 7.04% | 0.542 |
| E1 + 原始切割因子 | 0.0592 | 8.74% | 0.725 |
| E2 + 残差化切割因子 | 0.0581 | 7.63% | 0.611 |

方向一致（E1 > E0），但 bootstrap 置信区间覆盖 0，**不足以宣称显著**。

### 4.5 严格上游 OOS 堆叠（2021–2025）

这里有一个**方法论亮点**值得单独讲：

> 上游 DBD 得分从 2015 年才有样本外值，下游需要完整 5 年训练 + 1 年验证，
> 所以**下游第一个可测年是 2021**。
> 我没有用训练内得分去补 2015–2020 的年份——那样会把样本内信息混进样本外，IR 会虚高。

结果：直接加入 dbd_score 显著变差（Δ=−0.0102，CI [−0.0185, −0.0021]，共线性），
残差化后与基线持平但不显著。

### 4.6 子区间分解：长回测区间里最该看的一张表

| 策略 | 2015–2017 | 2018–2021 | **2022–2025** | 2018–2025 |
| --- | ---: | ---: | ---: | ---: |
| raw_reversal（原始切割） | 15.2% | 6.1% | **+6.4%** | 6.3% |
| raw_amplitude（原始切割） | 5.9% | 8.8% | +2.8% | 5.8% |
| dbd_two_factor（DBD） | 16.1% | 13.0% | **−1.1%** | 5.7% |
| alpha158_lgb（基线） | 18.2% | 9.9% | **+0.6%** | 5.2% |
| gru_amplitude | 5.2% | 6.4% | −5.6% | 0.3% |

**两个发现**：

1. 所有策略的表现都**系统性前重后轻**。2015 年各策略 +26.8% ~ +41.6%（杠杆牛），
   这段把全程 CAGR 抬了上去。
2. **神经类因子衰减得更厉害**：2022–2025 四年，DBD 两因子 −1.1%、GRU 振幅 −5.6%，
   而最朴素的原始切割因子 raw_reversal 仍有 +6.4%。
   **近四年里，越简单的反而越稳。**

这直接回答了"回测区间会不会太长"——**长度不是问题，只看全程数才是问题**。

## 5. 三个我自己得出的判断

1. **DBD 的架构先验是有效的，但不是免费的。**
   它相对普通 GRU 有稳健增益，但在沪深300 这个池子上换不来对原始因子或 Alpha158 的显著增量。
   研报的优异表现很可能部分来自**全 A/中小票池 + 中性化 + 指增约束**这三件本项目做不到的事。

2. **微观结构因子有清晰的容量边界。**
   研报自己的数据（沪深300 −5.76% < 中证1000 −9.84%）就是证据。
   做这类因子时，先想清楚池子，再谈效果。

3. **复现的价值在于定位差异，不在于对齐数字。**
   数字对不上时，能说清"哪一项数据缺失导致哪一步做不了"，
   比调参把数字凑上去有用得多——后者在面试里一问细节就崩。
