# 因子切割论 × DBD-GRU：研报复现审计与滚动样本外研究

> Reproduction audit of *“Factor Cutting Theory meets Deep Learning”* (开源证券, 2025-07-26)
> with an 11-fold walk-forward study on CSI 300, 2015-01-06 → 2025-12-31.

一个**可审计**的研报复现项目：不追求复刻研报的漂亮数字，而是把每一处
“研报口径 / 本项目实现 / 数据上做不到” 的边界显式写出来，再用统一的
样本外协议把因子重跑一遍，并给出显著性检验与子区间稳健性分解。

## 1. 研报讲了什么

**原始研报**：开源证券《因子切割论与深度学习的结合应用——市场微观结构研究系列（28）》，
魏建榕 S0790519120001、苏俊豪 S0790522020001，2025-07-26。
（研报著作权归开源证券所有，**本仓库不包含研报原文**，仅引用其公开方法论；
详见 [`LICENSE`](LICENSE) 中的第三方内容声明。）

### 1.1 因子切割论：三要素

传统反转因子 `Ret20` 收益强但稳定性差。研报的切入点是：**信息在时间轴上的分布是不均匀的**——
20 日的涨跌幅里，有些日子贡献强反转，有些日子贡献弱反转甚至动量。
于是把这段区间“切开”，只取信息含量高的部分。

由此抽象出三要素：

| 要素 | 含义 | 理想反转因子中的对应物 |
| --- | --- | --- |
| **对象** | 具有**可加性**的目标变量（切开后含义不变、可重新加总） | 日涨跌幅 |
| **刀法** | 有区分能力的**切割指标** | 日均单笔成交金额（成交金额 / 成交笔数） |
| **产出** | 对切割后变量的再加工（相减 / 相除） | `M = M_high − M_low` |

可加性是硬约束：涨跌幅、换手率、成交量、振幅都可加；**流通市值、市盈率不可加**，不能当切割对象。
“相减”除了提纯信息，还起到**标准化**作用——被减去的那一半不贡献收益，却提供了公允的水准线，
从而提升因子稳定性。

### 1.2 三个切割论因子

| 因子 | 切割指标 A | 切割对象 B | 产出 |
| --- | --- | --- | --- |
| 理想反转 | 日均单笔成交金额 | 日涨跌幅 | 高 10 日收益和 − 低 10 日收益和（`sum`，50%/50%） |
| 理想振幅 | 收盘价高低状态 | 日振幅 `high/low−1` | 高价 25% 日振幅均值 − 低价 25% 日振幅均值（`mean`） |
| 主动买卖（小单） | 收盘价高低状态 | 小单流入强度 | **只取**低价 25% 日的均值（**不相减**） |

底层逻辑（研报 P4–P5）：反转之力来源于跟风与过度反应，而大单成交多的时候这类行为更多，
后续反转更强——**反转的微观来源是大单成交**。所以用单笔成交金额切，能切得动。

### 1.3 DBD-GRU：把“切割”写进网络结构

输入 `x ∈ R^{20×2}`（A = 切割指标，B = 切割对象）。

1. 以 **A 在时序上的中位数**为阈值生成两个掩码：`mask_Ahigh`（`A ≥ 中位数`）、`mask_Alow`（`A < 中位数`）；
2. 掩码后的数据分别送入两个分支 `GRU_high` / `GRU_low`；
3. 取两分支**最后一个时间步隐藏状态之差** → Linear(64,1) 输出。

对照的普通 GRU 基线：同样 20×2 输入，**不做掩码**，直接取最后时间步。

> 关键点：DBD 不是“两个 GRU 的堆叠”，而是把**切割这一先验**编码进了架构，
> 参数量 GRU 38,081 / DBD-GRU 76,097（见 `model_parameters.json`）。

研报报告 DBD 因子在 201412–202505 上 RankIC 约 −10.3%，且**剔除切割论因子与 GRU 因子后仍有增量**，
反向则 GRU 因子剔除 DBD 后 RankIC 绝对值掉到 2% 以下。DBD-Combine 在中证 1000 指增上年化超额 11.8%、IR 2.21。

## 2. 本项目做了什么

在 **Qlib 社区数据 + 本人 Wind 导出成交笔数** 的条件下，尽最大可能对齐研报，
做不到的部分**明确标注而不是伪造**（22 项对照见 [`replication_matrix.csv`](replication_matrix.csv)）。

### 2.1 协议（与研报的差异是“项目扩展”，已显式声明）

| 项 | 研报 | 本项目 |
| --- | --- | --- |
| 股票池 | 全 A / 沪深300·中证500·中证1000 | **沪深300 历史成分**（范围收窄） |
| 训练窗口 | 5 年滚动，年底更新 | 5 年训练 + 1 年验证 + 1 年测试，**11 折** |
| 测试区间 | 2014-12-31 ~ 2025-05-30 | **2015-01-06 ~ 2025-12-31**（2,673 交易日） |
| 标签 | 未来 20 日收益 | `t+1` 收盘入场 → `t+21` 收盘出场（两端时点研报未明确） |
| 中性化 | 市值 + 行业中性 | **做不到**（缺 PIT 行业/市值），不做回填伪造 |
| 组合 | 约束指增（个股/行业/Barra/换手约束） | **Top50 等权、95% 仓位**的研究模拟，不冒充指增 |
| 网络超参 | hidden 64 / 2 层 / 100 epoch / 早停 20 | 同；其余（Adam lr 0.001、梯度裁剪 5、MAD 缩放 ±5）为**实现假设**，非研报披露 |

### 2.2 能复现 / 不能复现

**已实现**：理想振幅因子、理想反转因子、DBD 双分支结构与中位数掩码、5+1 滚动、
GRU 基线对照、对称正交合成、残差化增量检验、配对 bootstrap 显著性检验。

**做不到（数据缺失，不以替代品充数）**：
- 缺小单主动买/卖额 → **第三分支与三因子 DBD-Combine 无法运行**（全单买入不能替代）；
- 缺历史行业、市值、Barra、基准权重、完整 ST 与精确涨跌停 → **中性化与约束指增无法完成**；
- 成交金额为社区 Tushare 金额（千元 ×1000），**并非 Wind 金额**，与 Wind 成交笔数跨供应商拼接；
- 早年成交笔数缺失，**不填零**，见 `coverage_2009_2025.csv`。

## 3. 回测区间：2015-2025，会不会太长？

**结论：区间长度不是问题，但“只报一个总数”掩盖了近期衰减，这才是问题。**

### 为什么不算太长

1. 这是 **walk-forward**：每折用过去 5 年训练、前 1 年验证、下 1 年测试，**模型每年重训**。
   11 年 = 11 个相互独立的样本外年份，不是“一个模型跑 11 年”，长区间在统计上是**加分项**。
2. 研报自己的测试区间也有 10.5 年（2014-12 ~ 2025-05），本项目与其同量级。
3. 起点由数据决定：训练需要 5 年 + 验证 1 年 = 6 年预热，数据自 2009 年起，
   **首个可测年只能是 2015**——再往前就要牺牲训练窗口长度。

### 但长区间的三个真实代价（必须主动披露）

1. **早期数据质量更差**：Wind 成交笔数早年缺失多；Top50 组合中“缺价沿用最后价格”的持仓日
   2015 年 645 天、2017 年 818 天，近年几乎为 0。
2. **2015 杠杆牛 + 股灾主导早期分年结果**：2015 年各策略 +26.8% ~ +41.6%，把全程 CAGR 抬了上去。

### 子区间分解（这才是重点）

分年收益累乘得到的子区间 CAGR（`results_replication/yearly_portfolio.csv`）：

| 策略 | 2015–2017 | 2018–2021 | **2022–2025** | 2018–2025 |
| --- | ---: | ---: | ---: | ---: |
| raw_reversal（原始切割） | 15.2% | 6.1% | **+6.4%** | 6.3% |
| raw_amplitude（原始切割） | 5.9% | 8.8% | +2.8% | 5.8% |
| dbd_two_factor（DBD 两因子） | 16.1% | 13.0% | **−1.1%** | 5.7% |
| alpha158_lgb（基线） | 18.2% | 9.9% | **+0.6%** | 5.2% |
| gru_amplitude | 5.2% | 6.4% | −5.6% | 0.3% |

**这张表比任何全程指标都重要**：

- 神经类因子（DBD / GRU）的增量**主要集中在早期**；**2022–2025 四年里 DBD 两因子 CAGR 为 −1.1%，
  已经不再优于原始切割因子**（raw_reversal 同期 +6.4%）。
- 若只报“全程 CAGR 8.79%、IR 0.80”，会把这段衰减完全藏起来。
  本项目因此**默认同时给出分年与子区间结果**，不做单数字汇报。

> 建议做法：任何长区间回测都必须附子区间分解；如果只能报一个数，报**最近的子区间**并说明理由。

### 4.2 与研报口径的直接对比【关键】

研报摘要给出 DBD-Combine 在各宽基上的 RankIC：

| 股票池 | 研报 DBD-Combine | 本项目 | 差值 |
| --- | ---: | ---: | --- |
| **沪深300** | **−5.76%** | **−5.54%**（dbd_two_factor） | **0.22 pp** |
| 中证500 | −7.40% | 未测 | — |
| 中证1000 | −9.84% | 未测 | — |

两者在股票池（研报三因子 vs 本项目两因子）、区间、是否中性化上均有差异，
仍落在 0.22 个百分点内，**符号方向也一致（均为负）**——因子构造与 DBD 结构的复现是站得住的。

单因子量级弱于研报（本项目 −5.79% / −3.04% vs 研报全 A −10.33% / −10.3%），
原因恰恰写在研报自己的表格里：同一因子在沪深300(−5.76%) → 中证500(−7.40%) → 中证1000(−9.84%)
**单调变强**，即微观结构因子在大票上天然更弱。本项目池子正是沪深300。

### 4.3 显著性检验（配对移动块 bootstrap，块长 21 日，2,000 次）

来源 `results_replication/paired_tests.json`（数值为日频 RankIC 差值均值及 95% CI）：

| 对比 | Δ mean | 95% CI | 结论 |
| --- | ---: | --- | --- |
| dbd_amplitude − raw_amplitude | +0.0006 | [−0.0178, +0.0184] | 不显著 |
| **dbd_amplitude − gru_amplitude** | **+0.0589** | [+0.0420, +0.0761] | **显著为正** |
| dbd_reversal − raw_reversal | −0.0213 | [−0.0424, −0.0017] | **显著为负**（DBD 弱于原始因子） |
| dbd_reversal − gru_reversal | +0.0054 | [−0.0089, +0.0204] | 不显著 |
| dbd_two_factor − alpha158 | −0.0053 | [−0.0228, +0.0129] | 不显著 |

**诚实结论**：在本项目的沪深300、20 日标签、CPU 训练条件下，
**DBD 相对普通 GRU 的架构增益是稳健的**（振幅分支显著），
但 **DBD 相对原始切割因子、相对 Alpha158 基线并未取得统计上显著的增量**。
这与研报在全 A 池、更完整数据下的结论不同，差异来源已在 `replication_matrix.csv` 中逐条列出。

### 4.4 增量消融（`results_2015_2025` / `results_with_reversal`）

| 实验 | RankIC | CAGR | Sharpe | IR |
| --- | ---: | ---: | ---: | ---: |
| E0 Alpha158 基线 | 0.0585 | 7.04% | 0.415 | 0.542 |
| E1 + 原始切割因子 | 0.0592 | 8.74% | 0.482 | 0.725 |
| E2 + 残差化切割因子 | 0.0581 | 7.63% | 0.439 | 0.611 |

加入振幅 + 反转两因子的共同样本版本（`results_with_reversal`）中，
E0 / E1 / E2 的 CAGR 为 10.00% / 10.40% / 10.65%，IR 为 0.874 / 0.906 / 0.943——
增量方向一致，但 bootstrap 置信区间均覆盖 0，**不足以宣称显著**。

### 4.5 严格上游 OOS 堆叠（`results_stacking_2021_2025`，2021-01-05 ~ 2025-12-31）

上游 DBD 得分自 2015 年起才样本外可得，下游需要完整 5 年训练 + 1 年验证，
**因此首个可测年为 2021，不伪造早年的训练内得分**：

| 变体 | RankIC | CAGR | IR | vs A 的 Δ（95% CI） |
| --- | ---: | ---: | ---: | --- |
| A：Alpha158 | 0.0280 | 0.85% | 0.492 | — |
| B：A + dbd_score | 0.0178 | −0.35% | 0.315 | **−0.0102 [−0.0185, −0.0021]** |

即：直接把 DBD 得分塞进下游**显著变差**（共线性），残差化后与基线持平但不显著。

## 5. 交易与指标口径

- 月频调仓、Top50 等权、目标 95% 股票仓位；
- `t` 日收盘出信号 → `t+1` 收盘成交（**信息滞后一日，不做当日收盘价成交**）；
- 费用：买入 5bp / 卖出 15bp；持仓权重随价格漂移；
- 涨跌停用 **9.5% 对称收益代理**（不等于各板块/ST 真实涨跌停价）；
- 缺价持仓**沿用最后价格**并单独计数（`stale_position_days`），未处理真实退市清算、排队、容量、手数；
- IR 相对沪深300**价格指数**，Sharpe 无风险利率取 0；末 21 日无完整标签不计 IC，但组合估值到 2025 年底。

> **这是研究模拟，不是实盘业绩。**

## 6. 快速上手

Python 3.12。数据不在仓库内（见下节），先按 `download_data.py` 准备 Qlib 数据。

```bash
python -m pip install -r requirements_reproduction.txt   # 或 requirements.txt（引用版）

# 快速复核（不需要完整重跑）
python verify_data.py
python -m unittest discover -s tests
python test_timing.py
python run_neural_grid.py --prepare-only
python verify_current.py

# 完整重跑（CPU 上神经训练较慢；低内存机器用 --workers 1）
python reproduce_all.py --workers 2
```

默认复用已完成的神经模型检查点；如需从头训练，先把 `results_neural_grid/` 备份移出，
**不要只删某年预测却保留同名完成标记 JSON**。修改数据或特征后须同步清理缓存，不能混用旧模型与新输入。

## 8. 已知限制

- 参数量未做对齐对照（DBD 参数约为 GRU 的两倍）；只跑了单一随机种子 2026；
- 第三分支（主动买卖）与三因子 DBD-Combine 因数据缺失未运行；
- `package_deliverable.py` 引用了交付包内的 `environment_current.txt` 等文件，仓库中不含，直接运行会报缺失；
- 供应商提供的是**当前修订后的历史快照**，并非逐日历史版本，PIT 保证有限。
